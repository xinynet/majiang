# 预渲染麻将牌

`shells.png` 是 6 列 × 5 行的透明图集，包含 29 个有效姿态（-70° 到 +70°，每 5° 一帧）。每帧 180 × 252 像素，第 30 格留空。平面旋转仍然连续；倾倒按重力积分选择姿态帧。

生成器以同一个圆角长方体模型、正交相机和光源烘焙白色牌体、倒角高光及背面窄红边。`poses.js` 保存牌面与该相机一致的投影矩阵。图案沿用 `assets/tiles-face` 和现有万字 SVG，通过 multiply 混合叠在烘焙牌面上。

重新生成（Python 需安装 numpy、Pillow）：

```sh
python tools/bake-tiles.py
node tools/test-tile-motion.cjs
```

`preview.jpg` 为九种代表姿态的检查图，不在游戏中加载。

当前牌体宽高厚比例为 1 : 1.4 : 0.41，圆角半径为牌宽的 6.5%。相机基础俯角 10°；倾斜时主要绕横向轴转动，露出宽厚的下侧面，左右偏转只占姿态角的 16%。图集帧和牌面矩阵在动画中插值，避免逐帧跳变；触桌后有 220ms 的小幅回弹。

支撑模拟依据牌的位置、层级、邻牌关系重新计算，支持连锁下落和倾倒中重新失去支撑。按用户明确要求，动画默认开启，由游戏设置中的独立动画开关控制。它是面向现有 2.5D 布局的简化重力模拟，不包含完整刚体碰撞、摩擦滑移和任意形状接触求解。

素材按提供的截图调整外观，但不是原游戏源素材；现有动物图案也不全部等同于参考截图。若需要逐像素一致，应提供原始透明牌素材或原始三维模型、材质和相机参数。
